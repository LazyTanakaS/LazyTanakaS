## Featured projects
 
### [React-TypeScript](https://github.com/LazyTanakaS/React-TypeScript): Expense Tracker
 
Personal finance app for tracking income, expenses, monthly statistics, and subscriptions. Data persists in localStorage, and the components are typed.
 
Tech: React, TypeScript, Vite, Vitest, CSS | [Live Demo](https://lazytanakas.github.io/React-TypeScript/expenses-tracker/) | [GitHub](https://github.com/LazyTanakaS/React-TypeScript)
 
### [Court Interpreter Website](https://github.com/LazyTanakaS/bekasava-eu) (real client project)
 
Multilingual landing site for a certified court interpreter in Prague. It uses no UI libraries; everything is custom.
 
- i18n in 4 languages with a typed dictionary (`Record` keyed by a union of four language codes)
- Custom hooks: `useInView` on IntersectionObserver, `useCounter` on rAF
- Accessibility: aria-expanded, keyboard nav, focus-visible, reduced-motion
- Scrollspy navigation and custom SVG icons
Tech: React, TypeScript, Vite, CSS | [Live Demo](https://lazytanakas.github.io/bekasava-eu/) | [GitHub](https://github.com/LazyTanakaS/bekasava-eu)
 
### [Car Service Log](https://github.com/LazyTanakaS/car-service-log)
 
Personal car maintenance log. You can record, edit, and filter service entries by car part, and the history is tracked by date and mileage. Data persists in localStorage.
 
Tech: React, TypeScript, Vite, Vitest, CSS | [Live Demo](https://car-service-log-phi.vercel.app/) | [GitHub](https://github.com/LazyTanakaS/car-service-log)
 
### [ETF Landing Page](https://github.com/LazyTanakaS/etf-landing-cz)
 
Landing page comparing US-listed ETFs for Czech retail investors, built with Claude Code as a take-home assignment. I reviewed the code and checked the calculations against values I worked out independently.
 
Tech: React, TypeScript, Vite, Vitest | [Live Demo](https://etf-landing-cz.vercel.app/) | [GitHub](https://github.com/LazyTanakaS/etf-landing-cz)
